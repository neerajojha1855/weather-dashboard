# Weather Dashboard
🌦️ Weather Dashboard Web App

A responsive weather dashboard web application built using HTML, CSS, and JavaScript that displays real-time weather information, air quality index (AQI), and a 3-day forecast for any city. The app integrates a third-party weather API and dynamically updates the UI based on user input.

✨ Features

Search weather by city name

Real-time temperature, humidity, wind speed, and visibility

Air Quality Index (AQI) display

3-day weather forecast

Dark/Light mode toggle with saved user preference

Responsive and user-friendly UI

🛠️ Tech Stack

HTML5

CSS3

JavaScript (ES6+)

REST API (WeatherAPI)
